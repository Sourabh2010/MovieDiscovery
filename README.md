




# 🎬 MovieDiscovery

MovieDiscovery is a modern Android application built with **Kotlin and Jetpack Compose** that allows users to discover movies, search for movies, and view detailed information about them using the **TMDB API**.

## ✨ Features

- 🔥 Browse Popular Movies
- 📈 Explore Trending Movies
- ⭐ Discover Top Rated Movies
- 🔍 Search Movies
- 🎬 View Movie Details
- 🖼️ Movie Posters and Backdrops
- ⭐ Movie Ratings
- 📅 Release Dates
- 🎭 Movie Genres
- ⏱️ Movie Runtime
- 📱 Modern Jetpack Compose UI
- 🌐 Real-time movie data using TMDB API
- 🔄 Loading, Error and Empty states

## 🛠️ Tech Stack

- **Kotlin**
- **Jetpack Compose**
- **MVVM Architecture**
- **Clean Architecture**
- **Hilt** – Dependency Injection
- **Ktor Client** – Networking
- **Kotlinx Serialization** – JSON Serialization
- **Coil** – Image Loading
- **Navigation Compose**
- **Kotlin Coroutines**
- **StateFlow**
- **TMDB API**

## 🏗️ Architecture

The application follows a **Clean Architecture + MVVM** approach.
